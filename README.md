# ImGoaTeX
ImGoaTeX : Improved Graphics and Objectivly more Accessible than TeX - A programming language inspired by LaTex's Beamer library that lets you create beautifully structured presentations that compile directly to HTML, giving you access to features traditional PDFs lacks

## First usage

Write a presentation (such as the `main.igtex` file) and then compile it by doing `python3 ImGoaTeX-compilor.py [filename]`

it will render a portable, standalone(by default) HTML file of your presentation titled `output.html`, you can take that `.html` file and open it in your browser of choice to view your presentation !
